📊 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

ENDPOINT 1: GET /api/analytics/solana
─────────────────────────────────────────────────────────────────────────────

Query Parameters:
  • start_date (optional): YYYY-MM-DD
  • end_date (optional): YYYY-MM-DD
  • timeframe (optional): daily|weekly|monthly|yearly (default: daily)

Example:
  /api/analytics/solana?start_date=2024-01-01&timeframe=weekly

Response:
  {
    "data": [
      {"date": "2024-01-01", "profit_sol": 0.5, "profit_usd": 100.0, ...}
    ],
    "summary": {
      "total_profit_sol": 5.0,
      "total_profit_usd": 1000.0,
      "total_loss_sol": -2.0,
      "total_loss_usd": -400.0,
      "net_profit_sol": 3.0,
      "net_profit_usd": 600.0,
      "total_trades": 20,
      "winning_trades": 15,
      "losing_trades": 5,
      "win_rate": 75.0
    }
  }

Data Source: backend/solana_trades.json
Filter: status == "Success" only
Calculation: profit_sol = amount_out - amount_in

─────────────────────────────────────────────────────────────────────────────

ENDPOINT 2: GET /api/analytics/tokocrypto
─────────────────────────────────────────────────────────────────────────────

Query Parameters:
  • start_date (optional): YYYY-MM-DD
  • end_date (optional): YYYY-MM-DD
  • timeframe (optional): daily|weekly|monthly|yearly (default: daily)

Example:
  /api/analytics/tokocrypto?timeframe=monthly

Response:
  {
    "data": [
      {"date": "2024-01", "profit_usdt": 100, "cumulative_profit": 100}
    ],
    "summary": {
      "total_profit_usdt": 500,
      "total_loss_usdt": -200,
      "net_profit_usdt": 300,
      "total_trades": 20,
      "winning_trades": 15,
      "losing_trades": 5,
      "win_rate": 75.0
    }
  }

Data Source: crypto_bot.db (SQLite database)
Filter: status == 'CLOSED' only
Calculation: profit_usdt from database field
